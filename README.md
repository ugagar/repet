# repet

## Требования
1. Вести записи расписаний уроков 
2. Быстро переходить к уроку с учеником
3. Иметь доступ к файлам: презентации, доски, pdf и docx файлы с материалом уроков 
4. Домашние задания. назначать ученикам домашку, выставлять сроки, возможность отметить и показать ошибки

## Реализация

Далее будут даны краткие описание сервисов и модулей из этих документов (без подробностей)

### 1. Расписание
Модуль приложения отвечающий за создание, хранение и отображение расписания.

### 2. Урок
Следит за запуском урока. Хранит статус проведения урока, тему, ссылки на домашнее задание и документы успользуемые в уроке

### 3. Хранилище файлов
Ограниченное по объему файловое хранилище. Зранит документы, похволяет получать и делиться доступом к ним через интерфейс.
